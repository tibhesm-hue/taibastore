☁️ تفعيل الحفظ بالإيميل في رابط الإتقان

خطوات تسويها مرة وحدة من جوالك في Cloudflare. الأزرار مكتوبة بأسمائها الإنجليزية كما تطلع في الموقع، وجنبها معناها.

١) أنشئ قاعدة البيانات

  1. افتح موقع Cloudflare وسجّل دخولك: dash.cloudflare.com
  2. من القائمة ☰ اختر Storage & Databases = التخزين وقواعد البيانات، ثم D1 SQL Database
  3. اضغط Create = إنشاء، واكتب الاسم itqan، ثم اضغط Create مرة ثانية

٢) اربطها ببرنامج التصحيح

  1. من القائمة ☰ اختر Workers & Pages، ثم اضغط على taj-asr
  2. افتح تبويب Bindings = الروابط، واضغط Add binding = إضافة ربط
  3. اختر D1 database، واكتب في Variable name = اسم المتغير: DB
  4. اختر قاعدة البيانات itqan، ثم اضغط Add binding أو Deploy

٣) الصق الكود الجديد

  1. اضغط الزر الأخضر تحت «انسخ الكود»
  2. في صفحة taj-asr اضغط Edit code = تعديل الكود (رمز )
  3. امسح الكود القديم كله، والصق الجديد مكانه
  4. اضغط Deploy = نشر

٤) تأكّد

  1. افتح هذا الرابط: taj-asr.yaqot-tibh.workers.dev
  2. إذا شفت فيه "itq":true معناه اشتغل ✓، وصار رابط الإتقان يدخل بالإيميل
  3. إذا شفت "itq":false معناه الربط في الخطوة ٢ ما تم
